# DSA Quiz — Native Android Application (Java)

An interactive, pastel-themed Data Structures & Algorithms (DSA) Quiz & Learning application built natively in **Java** using **Android Studio** and **Room Database**.

---

## 🌟 Key Features
- 📚 **Study & Practice Modes**: Learn core algorithmic concepts with cheat-sheet explanations.
- ⏱️ **Timed Challenge Quizzes**: 30-second per-question timer with 50:50 lifelines.
- 🎯 **8 Core DSA Topics**: Arrays, Linked Lists, Stacks & Queues, Trees, Graphs, Sorting, Dynamic Programming, and Time Complexity.
- 🏆 **Leaderboard Podium**: Gold, Silver, and Bronze podium rankings.
- 📊 **Statistics & Mastery Progress**: Track overall accuracy %, lifetime points, day streaks, and topic progress wheels.
- 📝 **Review Answers Screen**: Full review of submitted answers vs correct options with technical explanations.
- 💾 **Local Offline Storage**: Powered by Room (SQLite ORM) for offline-first performance.

1. Clone this repository:
   ```bash

   ```

3. Allow Gradle to sync dependencies.
4. Run on an emulator (Pixel 7 / API 24+) or physical Android device.
